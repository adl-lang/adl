# adl_rt_derive

Derive macros supporting rust code generated by [adlc], the compiler for the
[Algebraic Data Language][adl].

You almost certainly want [`adl_rt`] instead, which depends on this crate and
re-exports it. It exists separately only because rust requires a procedural
macro to live in its own crate.

It provides one derive, `AdlAnnotations`, which introduces the
`#[adl_annotation(...)]` attribute:

```rust,ignore
#[derive(Clone, /* ... */ adl_rt::AdlAnnotations)]
#[adl_annotation(name="common.http.HttpPath", value="\"/\"")]
pub struct ApiRequests { /* ... */ }
```

adlc emits that attribute for every ADL annotation whose declaration is marked
`adlc.config.rust.RustEmitAnnotation`, carrying the annotation's scoped name and
its value in ADL's json encoding. The derive generates no code: rust rejects an
attribute that no derive on the item has registered as a helper, so its whole
purpose is to make the attribute legal and inert. Other derive macros on the
same item can then read it, since helper attributes are visible to every macro
rather than only the one that declared them.
